overrideIndexTriggers
======================
Allows overriding default treatment of branch indexing triggers.

If branch indexing triggers are disabled at the multibranch or organization label, 
options { overrideIndexTriggers(true) } will enable them for this job only. 

Otherwise, options { overrideIndexTriggers(false) } will disable branch indexing triggers for this job only.

https://github.com/bhanuprakash678910/overridetriggers.git


create multi branch pipeline with 1 minute index.

node {

	properties(
		[
			//overrideIndexTriggers(false)
		]
	) 

    stage('Build') {	
		echo 'Hello World 1'
    }	
}

node {

	properties(
		[
			//overrideIndexTriggers(false)
		]
	) 

    stage('Build') {	
		echo 'Hello World 2'
    }

In Jenkins, overrideIndexTriggers is an option used in declarative pipelines to override the default behavior of indexing triggers.

 By default, Jenkins will use the triggers defined in the pipeline script, but this option allows you to explicitly specify which triggers should be used for indexing.

In this example, we have a declarative pipeline defined with the overrideIndexTriggers option set to true. This means that Jenkins will use the trigger defined in the triggers block  instead of the triggers defined in the pipeline script.


pipeline {	
    agent any	
    options {	
		timestamps()
		overrideIndexTriggers(false)
	        overrideIndexTriggers(env.BRANCH_NAME == 'dev')
    }
    stages {	
        stage('Build') {	
            steps {
                echo 'Hello World 4-1'
		echo env.BRANCH_NAME
            }	
        }	
    }	
}
