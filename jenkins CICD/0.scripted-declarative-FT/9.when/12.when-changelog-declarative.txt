changelog ( commit message)
==========
Execute the stage if the build’s SCM changelog contains a given regular expression pattern, for example: 

when { changelog '.*^\\[DEPENDENCY\\] .+$' }.

https://github.com/bhanuprakash678910/when-changelog.git

It builds if commit message has this regular expression.

cat Jenkinsfile
pipeline {
    agent any
    stages {
        stage("Build") {
            when {
                changelog '.*some_text.*'
            }
            steps {
                echo "Hello World changelog"
            }
        }
    }
}


 git commit -m "test some_text message"
