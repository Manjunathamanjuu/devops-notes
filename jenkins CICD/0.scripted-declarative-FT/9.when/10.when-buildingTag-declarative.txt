buildingTag
===========
Execute the stage when the build is building a tag. For example: when { buildingTag() }

when-BuildingTag 
================

https://github.com/bhanuprakash678910/pipeline-buildingtag.git

Here, we have single branch master and a single Jenkins file.

So in here we are specified that the state should only execute when we are building from a tag.

pipeline {
    agent any
    stages {
        stage("Build Master") {
            when {
              buildingTag()
            }
            steps {
                echo "Hello World Building Tag"
            }
        }
    }
  }
